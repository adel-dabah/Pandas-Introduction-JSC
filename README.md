# 📊 Introduction to Pandas

This repository contains all materials for the “Introduction to Pandas” training session. It is structured to support both teaching and hands-on learning, including slides, exercises, and solutions.

---

## 📁 Contents

### 🧑‍🏫 Teaching Materials
- Introduction-to-Pandas--master.ipynb  
  Main notebook used by the instructor during the session.

- Introduction-to-Pandas--slides.ipynb  
  Notebook formatted as presentation slides.

- slides_1.ipynb  
  Additional slide content.

- slides_1.slides.html  
  HTML version of the slides.

- slides_2026_2.pdf  
  PDF version of the slides.

---

### 🧪 Exercises
- Introduction-to-Pandas--tasks.ipynb  
  Hands-on exercises for participants.

---

### ✅ Solutions
- Introduction-to-Pandas--solution.ipynb  
  Solutions to the exercises.

---

## 🚀 How to Use

### For Participants
1. Start with the slides (.html or .pdf).
2. Open the tasks notebook and solve exercises.
3. Check solutions afterward.

### For Instructors
- Use the master notebook for teaching.
- Present using slides.
- Guide participants through tasks.

---

## 🛠 Requirements
- Python 3.x
- Jupyter Notebook or JupyterLab
- Pandas

Install with:
pip install pandas notebook

---

## 🎯 Learning Objectives
- Understand Pandas data structures
- Load and inspect datasets
- Perform data manipulation
- Handle missing data
- Perform basic analysis
